# Kolawole Ogunniyi — Personal Portfolio

Static HTML/CSS portfolio for the COSC 484 extra-credit assignment.

## Publish the required GitHub Pages URL

1. Sign in to the GitHub account **ko449-wq** at https://github.com/new.
2. Create a **PUBLIC** repository named exactly **ko449-wq.github.io**. Do not initialize with a README.
3. Open the new repository, choose **Add file → Upload files**, and drag in **index.html**, **styles.css**, and **Kolawole_Ogunniyi_Resume.pdf** from this folder (or from the downloaded ZIP after extracting it). Commit to `main`.
4. In the repository, go to **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, then Save.
5. Visit **https://ko449-wq.github.io/** and verify the site and résumé link load.
6. Submit **https://ko449-wq.github.io/** on Blackboard before **October 12, 2026 at 2:00 PM Eastern**.

The site requires no Node.js, npm, build step, or API key. You can preview by opening `index.html` in a browser.
